# 📝 Redação 5.0

**Redação 5.0** é um projeto desenvolvido em Python, com interface gráfica, que reúne ferramentas de automação e interação com o computador.

O projeto utiliza bibliotecas que permitem criar uma interface visual, controlar ações do mouse e teclado e apresentar mensagens ao usuário.

## 🚀 Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- **Python** — Linguagem principal.
- **CustomTkinter** — Criação da interface gráfica.
- **PyAutoGUI** — Automação de mouse e teclado.
- **Pynput** — Monitoramento e controle de dispositivos de entrada.
- **CTkMessagebox** — Exibição de caixas de diálogo personalizadas.

## 📦 Instalação

### Pré-requisitos

- Python instalado.
- Git instalado (opcional).

### 1. Clone o repositório

```bash
git clone https://github.com/JpStar06/redacao-5.0.git
```

### 2. Entre na pasta do projeto

```bash
cd redacao-5.0
```

### 3. Crie um ambiente virtual

```bash
python -m venv venv
```

### 4. Ative o ambiente virtual

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Instale as dependências

```bash
pip install -r requirements.txt
```

## ▶️ Como executar

Após instalar todas as dependências, execute:

```bash
python main.py
```
